# JPA Quote Builder — Enterprise Quotation & Rate Library Portal

Enterprise B2B Quotation, Rate Library, and Multimodal AI Extraction Portal (`JPA Vision AI` & `JPA Qwen`) for **Jeevan Pranav Agencies (JPA)**.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
